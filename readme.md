# Awafi Project

هيكل المشروع الآن منظم كالتالي:

- `index.html` — صفحة البداية الرئيسية
- `about.html` — صفحة التعريف بالمصنع
- `products.html` — صفحة عرض المنتجات مع تصفية حسب العوائل
- `contact.html` — صفحة التواصل
- `thanks.html` — صفحة الشكر بعد الإرسال
- `family.html` — صفحة عرض تفاصيل العائلة مع كاروسيل وأصناف
- `assets/js/components.js` — سكريبت القوائم والفوتر والنافبار المشترك
- `assets/js/products-data.js` — بيانات المنتجات والعوائل
- `assets/images/` — صور المشروع المستخدمة في الصفحات

## العوائل الحالية:

- **عائلة الشهره**: شطة، كاتشب، صلصة طماطم
- **عائلة الذ**: خل
- **عائلة اللحظة**: (فارغة حالياً)
- **عائلة الشهره اليمنية**: (فارغة حالياً)

## ملاحظات

- في صفحة المنتجات، يتم عرض العوائل كأقسام منفصلة مع عنوان وشرح لكل عائلة
- كل عائلة تحتوي على كاردات منتجاتها
- النقر على "استكشف العائلة" يفتح صفحة العائلة مع التمرير للصنف المحدد
- صفحة العائلة تحتوي على كاروسيل وgrid للأصناف
- سهل إضافة منتجات وعوائل جديدة عبر تعديل `products-data.js`
